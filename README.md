# CSP Optimizer — תמהיל Cash-Secured Puts על מניות גדולות

כלי שרץ ב-GitHub Actions, שולף שרשראות אופציות חיות ומחזיר **תמהיל חוזי Put לפרמיה מקסימלית**
בתוך רמת סיכון ובהון שאתם מגדירים, כולל **ההון הנדרש** לכל שורה ובסך הכול.

## מה מקבלים בכל הרצה

* **סיכום ב-GitHub** (Job Summary): פרמטרים, פרמיה שתיגבה, תשואה שנתית, הון נדרש,
  מזומן פנוי, הפסד בתרחישי קיצון, Monte Carlo, טבלת החוזים, והשוואה בין 4 רמות הסיכון באותו הון.
* **Artifact** עם `report.md`, `portfolio.csv`, `summary.json`, `risk_comparison.csv`,
  `chain_raw.csv` (הנתונים הגולמיים) ו-`chain_scored.csv` (כל החוזים עם המדדים).
* אופציונלית: שמירת הדוח בריפו תחת `results/` (`results/LATEST.md` תמיד מעודכן).

## הקמה (5 דקות)

1. צרו ריפו (מומלץ **Private**) והעלו אליו את התיקייה הזו.
2. **Settings → Secrets and variables → Actions → New repository secret**. הוסיפו לפחות מקור אחד:

| Secret | מקור | עלות | הערות |
|---|---|---|---|
| `BARCHART_API_KEY` | Barchart OnDemand (`getEquityOptions`) | בתשלום, דרך פנייה ל-Barchart | ה-API הרשמי של Barchart. **אין גרידה של barchart.com** |
| `TRADIER_TOKEN` | Tradier | חינם עם חשבון ברוקר Tradier | זמן אמת + Greeks. ל-Sandbox (השהיה של 15 דק', בלי Greeks) הגדירו Variable בשם `TRADIER_SANDBOX=1` |
| `MARKETDATA_TOKEN` | MarketData.app | Free = 100 קרדיטים ליום (לא מספיק); Starter בתשלום | כל חוזה בשרשרת = קרדיט |
| (ללא) | yfinance (Yahoo) | חינם | לא רשמי; נחסם לעיתים קרובות מ-GitHub Actions |
| (ללא) | Cboe delayed quotes | חינם | נקודת קצה ציבורית לא רשמית, השהיה של 15 דק' |

   במצב `auto` הסדר הוא: barchart → tradier → marketdata → yfinance → cboe. לכל מניה נלקח
   המקור הראשון שעובד. אם מקור נכשל, עוברים אוטומטית לבא.

3. **Actions → CSP optimizer → Run workflow**, ומלאו פרמטרים:

| קלט | משמעות |
|---|---|
| `capital` | ההון בדולרים |
| `risk` | `very_low` / `low` / `medium` / `high` |
| `objective` | `max_premium` (ברירת מחדל) או `target` (מינימום סיכון ליעד) |
| `target` | יעד תשואה שנתית על ההון, למשל `0.10` (רק במצב `target`) |
| `overrides` | עקיפת כל פרמטר סיכון ב-JSON, למשל `{"max_delta":0.15,"max_dte":30,"min_tickers":6}` |
| `tickers` | רשימה מותאמת (ריק = `config/universe.csv`, כ-30 מהגדולות) |
| `provider` | מקור נתונים |

4. **הרצה מתוזמנת:** ימים א'–ה' (שני–שישי בארה"ב) ב-16:30 UTC, כלומר 18:30 בישראל, כשהשוק פתוח.
   ערכי ברירת המחדל של ההרצה המתוזמנת נקבעים ב-Variables: `CSP_CAPITAL`, `CSP_RISK`,
   `CSP_OVERRIDES`, `CSP_TICKERS`, `CSP_PROVIDER`.

## אפליקציית Streamlit (ממשק אינטראקטיבי)

`app.py` הוא ממשק בדפדפן: בוחרים הון, רמת סיכון ומניות, מכווינים כל פרמטר סיכון עם סליידרים,
ורואים את התמהיל, ההון הנדרש, השוואה בין רמות הסיכון ו-Monte Carlo. הנתונים נשמרים במטמון ל-15 דקות,
כך ששינוי פרמטרים לא שולף אותם מחדש.

**העלאה ל-Streamlit Community Cloud (חינם):**
1. נכנסים ל-https://share.streamlit.io ומתחברים עם GitHub.
2. **Create app → Deploy a public app from GitHub**, ובוחרים: Repository = הריפו הזה, Branch = `main`, Main file = `app.py`.
3. ב-**Advanced settings**: Python 3.12, ובשדה **Secrets** מדביקים (ראו `.streamlit/secrets.toml.example`):
   `TRADIER_TOKEN = "..."`
4. **Deploy**. אחרי 2–3 דקות מתקבלת כתובת קבועה.

הרצה מקומית: `pip install -r requirements.txt` ואז `streamlit run app.py`.

## רמות הסיכון

| פרמטר | very_low | low | medium | high |
|---|---|---|---|---|
| דלתא מקס' לחוזה | 0.12 | 0.20 | 0.30 | 0.40 |
| דלתא ממוצעת מקס' | 0.10 | 0.16 | 0.24 | 0.32 |
| ימים לפקיעה | 21–45 | 14–45 | 7–60 | 7–60 |
| משקל מקס' למניה / לסקטור | 15% / 30% | 20% / 35% | 30% / 45% | 40% / 60% |
| כרית מזומן | 20% | 10% | 5% | 0% |
| הפסד מקס' בירידת שוק (20–25% × בטא) | 5% | 8% | 12% | 18% |
| הפסד מקס' מצניחת מניה בודדת (25–30%) | 1.5% | 2.5% | 4% | 6% |
| כרית מינ' עד נקודת איזון | 7% | 5% | 3% | 1% |
| מינ' מניות שונות | 6 | 5 | 4 | 3 |
| הימנעות מחוזים שחוצים דוחות | כן | כן | לא | לא |

את כל הפרמטרים אפשר לשנות דרך `overrides`. השמות מופיעים ב-`csp/engine.py` (`RiskProfile`).

## האלגוריתם

1. **שליפה:** חוזי Put בטווח הימים לפקיעה, מחיר המניה, היסטוריית מחירים של שנה
   (לחישוב תנודתיות היסטורית ל-60 יום ובטא מול SPY) ותאריך הדוחות הבא (מ-yfinance; כשהוא לא זמין מוצגת אזהרה).
2. **ניקוד:** mid, ‏IV (נפתר מהמחיר אם חסר), דלתא, תשואה על הביטחונות (לתקופה ושנתית), הסתברות לפקוע מחוץ לכסף,
   נקודת איזון, כרית, הפסד בשני תרחישי קיצון, ו"יתרון" (הפרמיה מול התשלום הצפוי לפי התנודתיות ההיסטורית).
3. **אופטימיזציה (MILP במספרים שלמים, HiGHS דרך scipy):** כמה חוזים מכל Put, כך שהפרמיה בקצב שנתי מקסימלית,
   בכפוף לגיבוי מלא במזומן, תקרות משקל למניה ולסקטור, תקרת דלתא ממוצעת, שני תרחישי הקיצון ומספר מניות מינימלי.
4. **Monte Carlo:** מודל עם גורם שוק משותף וזנבות עבים, עד הפקיעה. מחזיר הסתברות להפסד, הסתברות להקצאה, VaR ו-CVaR.

## מגבלות

* מחירים לפי mid; ביצוע בפועל, במיוחד בחוזים עם מרווח רחב, יהיה גרוע יותר.
* החישוב הוא עד הפקיעה. הוא לא מתחשב בהקצאה מוקדמת, בגלגול חוזים, בדיבידנדים או במס.
* שמות השדות של Barchart OnDemand נבנו לפי התיעוד, עם כמה שמות חלופיים, אבל לא נבדקו מול מפתח אמיתי.
  בהרצה הראשונה בדקו את `chain_raw.csv`.
* מקורות לא רשמיים (Yahoo, Cboe) עלולים להשתנות או להיחסם בלי הודעה מראש. בדקו את תנאי השימוש שלהם.
